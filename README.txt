THE COMMON TABLE — Restaurant Portfolio Website

Fictional restaurant demo, not a real business.

Files:
- index.html: upload to the root of your GitHub repository.
- restaurant-website.txt: same source code in TXT format for copying into GitHub.

GitHub Pages:
1. Create a public repository, e.g. common-table-restaurant.
2. Upload index.html to the repository root.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Visit https://YOUR-USERNAME.github.io/common-table-restaurant/

Interactive features:
- Menu category filters work.
- Request a Table buttons open a functional demo inquiry modal.
- Form validates fields and shows a preview, but DOES NOT send or book reservations.

Before using for a real business, replace sample menu, prices, hours, images, address and branding, obtain image rights, and connect a legitimate reservation provider or backend.
